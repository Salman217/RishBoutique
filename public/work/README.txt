RISH BOUTIQUE — WORK PHOTOS

1. Put your photos here (JPG, PNG, or WEBP).
   Good names: pattu-finish-01.jpg, cotton-pleats-02.jpg

2. Open src/data/gallery.js in the project and add one object per photo:

   {
     src: '/work/pattu-finish-01.jpg',
     caption: 'Short description for customers',
     tag: 'Pattu',
     featured: false,
   }

   Set featured: true on ONE photo for the large hero tile.

3. Save and refresh the website (npm run dev).

Tips:
- Use bright, clear photos of folded or draped sarees after ironing.
- Avoid blurry shots; show borders, pleats, and packaging if you can.
