# Rish Boutique — Landing Page

Premium landing page for saree ironing and finishing (branded cotton, pattu, silk blends).

Inspired by the structure of [United Carriers](https://unitedcarriers.com/): bold hero, stats band, services grid, process milestones, testimonials, FAQ, and contact CTA.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Customize

- **Phone / WhatsApp**: edit the `tel:` and `wa.me` links in `src/App.jsx` (Contact section).
- **Copy & process steps**: edit arrays at the top of `src/App.jsx`.
- **Work photos**: add JPG/PNG files to `public/work/`, then register them in `src/data/gallery.js` (see `public/work/README.txt`).
- **Colors**: tweak `src/index.css` `@theme` variables.
